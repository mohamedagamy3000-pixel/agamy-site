# موقع محمد عجمي

موقع بورتفوليو ثنائي اللغة (عربي/إنجليزي)، HTML و CSS و JavaScript عادي — من غير أي أدوات بناء
ولا `npm install`. أي متصفح يقدر يفتحه، وأي استضافة تقدر تشغّله.

---

## ١. اللي لازم يتعمل قبل النشر

| # | إيه | فين |
|---|---|---|
| ١ | **روابط السوشيال** — واحذف اللي مش عندك | `index.html` → قسم `<div class="socials">` |
| ٢ | **صورتك الشخصية** — آخر صورة ناقصة | `assets/img/portrait.jpg` |
| ٣ | **الشوريل** (اختياري) — حط ID الفيديو | `assets/js/content.js` → `reel` |

الإيميل متحط خلاص: `mohamedagamy3000@gmail.com` (في `index.html`، مكانين في نفس السطر).

الستيلز ولقطة أول الصفحة **متحطّين خلاص** — ١٦ لقطة متسحوبة من مشاريعك على Behance.

من غير الخطوات دي الموقع هيشتغل عادي، بس هيبان فيه مربعات رمادية مكتوب عليها
«صورة الفيلم هنا» — وده مقصود، عشان تعرف ناقص إيه.

---

## ٢. الستيلز — ده قلب الموقع

الموقع مبني على قاعدة واحدة: **الصورة قبل الكلام.** الترتيب:

```
أول الصفحة (لقطة كبيرة)  →  معرض الستيلز  →  الأفلام المتصوّرة
    →  الخدمات  →  عني  →  تحت التطوير (سطور مختصرة)  →  تواصل
```

مشاريعك اللي تحت التطوير نزلت تحت خالص في سطور من غير صور — عن قصد.
المنتج أو العميل بيشتري اللي شُفته، مش اللي هتعمله.

### إزاي تضيف لقطات

١. حط الصور في `assets/img/stills/` (أي أسامي إنجليزية من غير مسافات).
٢. افتح `assets/js/content.js` وزوّد سطر لكل لقطة في `gallery`
   (فيه ١٦ لقطة موجودة أصلًا — شوف شكلها واتبعه):

```js
gallery: [
  { src: "assets/img/stills/el-hadsa-01.jpg", caption: { ar: "الحادثة", en: "The Accident" } },
  { src: "assets/img/stills/el-hadsa-02.jpg" },
],
```

* **الـ `caption` اختياري** — سيبه لو مش عايز اسم يظهر على الصورة.
* **أي مقاس بيشتغل** — عريض، طولي، مربع. التصميم بيرتّبهم لوحده.
* الضغط على أي لقطة بيفتحها كبيرة، والأسهم بتنقّل بينهم.

### قواعد الاختيار (مهمة أكتر من العدد)

* **١٢ إلى ١٨ لقطة.** أكتر من كده الزائر بيسيب الصفحة.
* **لقطة واحدة قوية أحسن من عشرة عاديين.** لو مترددة في واحدة — شيلها.
* **أقوى تلات لقطات يبقوا الأول** — دول اللي بيتشافوا قبل أي سكرول.
* نوّع: وشوش، مساحات واسعة، تفاصيل، ليل ونهار. متحطش ٦ لقطات من نفس المشهد.

## ٣. الصور

حطها بالأسامي دي بالظبط:

```
assets/img/hero.jpg                  لقطة أول الصفحة   ✅ متحطة
assets/img/stills/*.jpg              ١٦ لقطة المعرض     ✅ متحطة
assets/img/portrait.jpg              صورتك الشخصية      ← الوحيدة الناقصة (طولية ٤:٥)
```

مشاريع «تحت التطوير» بتظهر سطور نصية من غير صور — **مش محتاجة بوسترات**.
لو حبيت تحط بوستر لواحد منهم، حط الصورة في `assets/img/work/` وحط مسارها
في `poster` بتاع المشروع في `content.js`، وغيّر `stage` لـ `"produced"`.

بوسترات الأعمال طولية (٤:٥) ما عدا **أول عمل في القايمة** — ده بيتعرض عريض (٢١:٩)
على الشاشات الكبيرة، فاختار له صورة عرضية أو صورة تتقص عرضي من غير ما تخسر حاجة.

اضغط الصور قبل ما ترفعها (JPG بجودة ٧٥–٨٠٪). صورة ٤ ميجا هتبطّأ الموقع بجد.

## ٤. إزاي تضيف أو تعدّل عمل

كل حاجة في ملف واحد: **`assets/js/content.js`**

* **تعديل:** غيّر النص في `ar` و `en`.
* **إضافة:** انسخ بلوك كامل من `{` لـ `},` وحطه في المكان اللي عايزه. لازم يكون له
  `id` مختلف (بالإنجليزي وبدون مسافات) — لأن ده اللي بيبقى في اللينك.
* **إخفاء مؤقت:** غيّر `published: true` لـ `published: false`.
* **الترتيب:** الترتيب في الملف هو الترتيب في الموقع. **حط الأقوى فوق.**
* **`stills`** = كل صور المشروع. لما حد يدوس على المشروع أو صورته، بيدخل
  صفحته وبيلاقي الصور دي كلها، وأي صورة بتكبّر بالضغط عليها (والأسهم بتنقّل).
* **`video`** = فيديو المشروع. الشكل:
  `video: { provider: "vimeo", id: "1197439509" }` — الـ id هو الرقم اللي في
  لينك الفيديو. (يوتيوب: `provider: "youtube"` والـ id هو الكود بعد `?v=`.)
  **شرط:** لازم الفيديو يكون مسموح تضمينه — في Vimeo:
  Settings → Privacy → «Where can this be embedded?» → Anywhere.
* **`stage`** بيحدد العمل يظهر فين:
  * `"produced"` → قسم «أفلام» فوق، بشبكة صور كبيرة.
  * `"development"` → قسم «تحت التطوير» تحت، سطر مختصر من غير صورة.
  * **لو مفيش ولا عمل `produced`، قسم «أفلام» بيتخفي لوحده** — مش بيفضل فاضي.
  * في أول `works` فيه نموذج جاهز لعمل `produced` — شيل التعليق واملاه.

لو ضفت فيديو لعمل معيّن:

```js
video: { provider: "vimeo", id: "123456789" }
```

ولو ضفت ستيلز:

```js
stills: [
  "assets/img/stills/el-sayes-01.jpg",
  "assets/img/stills/el-sayes-02.jpg"
]
```

⚠️ **خد بالك:** اللوجلاينات الموجودة دلوقتي مكتوبة من ملفات مشاريعك، ومقصود فيها
إنها **متحرقش نهايات ولا مفاجآت**. لو هتوسّعها، فضّل تسيبها كده — الصفحة دي عامة.

## ٥. تعديل باقي النصوص

النصوص التانية (الهيرو، الخدمات، «عني»، التواصل) مكتوبة جوّه `index.html` مباشرة.
كل نص متكتب مرتين ورا بعض:

```html
<span lang="ar">النص العربي</span><span lang="en">The English text</span>
```

عدّل جوّه الـ `<span>` وخلاص. **متمسحش واحد منهم** — لو مسحت العربي هيبان فاضي
لما حد يفتح الموقع بالعربي.

---

## مهم: لما تعدّل CSS أو JavaScript

في آخر `index.html` و `work.html` و `404.html` هتلاقي الروابط كده:

```html
<link rel="stylesheet" href="assets/css/style.css?v=2">
<script src="assets/js/content.js?v=2"></script>
```

**كل ما تعدّل في `style.css` أو `content.js` أو `app.js`، زوّد الرقم** (`?v=2` → `?v=3`)
في الملفات التلاتة. من غير كده اللي زار الموقع قبل كده هيفضل شايف النسخة القديمة
لأن المتصفح بيحتفظ بنسخة عنده.

(لو ضفت صور بس، مش محتاج تزوّد الرقم.)

## ٦. تشغيل الموقع على جهازك

من الفولدر ده:

```bash
python3 -m http.server 4321
```

وافتح `http://127.0.0.1:4321` في المتصفح. (`Ctrl+C` عشان توقفه.)

فتح `index.html` بالدبل-كليك بيشتغل برضه، بس السيرفر أدق.

## ٧. النشر واختيار العنوان

### الحقيقة الأول

**مفيش استضافة مجانية بتديك عنوان من غير اسم المنصة فيه.** أي حل مجاني
هيبقى فيه `github.io` أو `netlify.app` أو `pages.dev`. العنوان النضيف
اللي فيه اسمك وبس — زي `mohamedagamyproducer.com` — **لازم يتشترى**.

### الاختيارات

| العنوان | التكلفة | فيه كلمة github؟ |
|---|---|---|
| `mohamedagamyproducer.pages.dev` | مجاني | **لأ** ✅ |
| `mohamedagamyproducer.netlify.app` | مجاني | لأ |
| `agamyproducer.github.io` | مجاني | أيوه |
| **`mohamedagamyproducer.com`** | ~١٢ دولار/سنة | **لأ** ⭐ |

**نصيحتي:** ابدأ بـ **Cloudflare Pages** (`pages.dev`) — مجاني، وفيه كلمة
producer، ومفيهوش github. ولما تجهز، اشتري `.com` وحوّله في ٥ دقايق من غير
ما يتغير أي حاجة في الموقع.

---

### أ) Cloudflare Pages — مجاني، بدون كلمة github

1. ارفع الفولدر ده على GitHub الأول (لو مش عامل حساب، اعمله):

```bash
git remote add origin https://github.com/USERNAME/REPO.git
git branch -M main
git push -u origin main
```

2. ادخل [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages**
   → **Create** → **Pages** → **Connect to Git** → اختار الريبو.
3. في إعدادات البناء سيب كل حاجة فاضية:
   - Framework preset: **None**
   - Build command: **(سيبه فاضي)**
   - Build output directory: **`/`**
4. في **Project name** اكتب `mohamedagamyproducer` — ده اللي بيحدد العنوان.
5. **Save and Deploy**. خلاص، الموقع على `https://mohamedagamyproducer.pages.dev`.

أي `git push` بعد كده بينشر لوحده.

### ب) GitHub Pages — مجاني، بس فيه github.io

اعمل ريبو باسم `USERNAME.github.io` بالظبط، ارفع عليه، وبعدين
**Settings → Pages → Source: Deploy from a branch → `main` / `root`**.

### ج) دومين باسمك (~١٢ دولار/سنة) — الأحسن

اشتري `mohamedagamyproducer.com` من [Cloudflare Registrar](https://domains.cloudflare.com)
(أرخص حاجة، بيبيع بسعر التكلفة) أو Namecheap.

**لو على Cloudflare Pages:** المشروع → **Custom domains** → **Set up a domain**
→ اكتب الدومين. بس كده، Cloudflare بيظبط الـ DNS لوحده.

**لو على GitHub Pages:** اعمل ملف اسمه `CNAME` (من غير امتداد) في الفولدر ده،
جواه سطر واحد فيه الدومين. وبعدين عند مسجّل الدومين:
- أربع سجلات `A`: `185.199.108.153` · `185.199.109.153` · `185.199.110.153` · `185.199.111.153`
- سجل `CNAME` لـ `www` على `USERNAME.github.io`

وبعدين **Settings → Pages → Custom domain** وفعّل **Enforce HTTPS**.

### عشان السيرش باسمك يشتغل

الموقع فيه بالفعل بيانات منظّمة (JSON-LD) بتقول لجوجل إن الصفحة عن شخص
اسمه **محمد عجمي / Mohamed Agamy**، منتج ومدير إنتاج في الإسكندرية، ومربوطة
بحساباتك على Vimeo و FilmFreeway و Behance و LinkedIn.

بس ده مش كفاية لوحده. **أهم حاجة تعملها بنفسك:** حط لينك الموقع في
كل حساباتك (Vimeo · FilmFreeway · Behance · LinkedIn · إنستجرام) وفي توقيع
الإيميل. جوجل بيرتّب حسب عدد المواقع اللي بتشاور على موقعك.

وبعد النشر بأسبوع، سجّل الموقع في
[Google Search Console](https://search.google.com/search-console) — مجاني،
وبيخلي جوجل يفهرس الموقع أسرع.
